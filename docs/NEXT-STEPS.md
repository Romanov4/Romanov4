# Доделки 3D-карусели (запланировано)

Основание: `docs/RESEARCH-LAYOUT.md` (схема комплекса по эпохам, источники).
Незавершённая заготовка кода: `docs/wip-annex-hall.patch` (крыло слева + зал 1970-х; применять выборочно, расположение зала в ней не по оси — переделать).

Оценка: ~2 ч последовательно или ~1–1,5 ч с агентами.

1. Крыло 1960-х: трёхэтажное, примыкает к левому торцу здания Тона на линии фасада вдоль площади (~10 мин).
2. Кассовый зал 1975–77 (В. И. Кузнецов): за зданием по центральной оси, на месте дебаркадера; 2 уровня + надстройка; пути и платформы начинаются за ним (~20 мин).
3. Дебаркадер 1851: металлический (Р. Желязевич), ≈107 × 27 м, за зданием по оси, над двумя путями — вместо деревянного навеса справа (~20 мин).
4. 2026: стеклянный дебаркадер с «парящей» кровлей (h≈15 м) над зоной выхода к поездам за кассовым залом + навесы над платформами (~20 мин).
5. Окружение: в царскую эпоху — старый Рязанский вокзал вместо Казанского; здание МЖА с часами справа (по решению заказчика); флагшток и контактная сеть по эпохам (~15 мин).
6. Тексты: карточки эпох, SVG-фолбэк, noscript, хроника лендинга (зал 1975–77) (~10 мин).
7. Проверки: все эпохи, крупные планы, мобильная версия, тёмная тема, консоль, axe (~15 мин).
8. Обновить публикацию (импорты three на jsDelivr) (~10 мин).
