# Дизайн-система «Ленинградский вокзал»

Токены и компоненты для одностраничного лендинга о реконструкции вокзала К. Тона (1849–1851, реставрация 2024–2026). Тон классический, официальный и деловой.

Файлы:

- `tokens.css` — переменные (палитра светлой и тёмной темы, семантические алиасы, шкалы).
- `components.css` — компоненты на токенах.
- `index.html` — витрина: палитра с контрастами, шрифты, шкалы, все компоненты в обеих темах.
- `contrast.py` — считает контраст по WCAG и вписывает таблицу в витрину.

## Принципы

1. **Фасад 1873 года.** Оштукатуренная стена в два тёплых тона. Фон спокойный, членения делаются тонкими линиями, а не тенями.
2. **Кессонный потолок.** Модуль 56px. Полоса `.coffers` со «светильником» отделяет крупные разделы.
3. **Гостиная XIX века.** Лепнина передана орнаментальной линейкой с ромбом, бархат — бордо, наборный паркет — ритмом линий в таблицах и списках.
4. **Смальта «Две столицы».** Насыщенная многоцветность допустима только в тёмном разделе `.section--night` и в полосе `.smalt-band`.
5. **Часовая башня.** Римские цифры разделов, крупные даты антиквой, симметрия в шапке.

## Подключение

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,500;0,600;0,700;1,500&family=PT+Sans:ital,wght@0,400;0,700;1,400&display=swap" rel="stylesheet">
<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">
```

Тема:

- по умолчанию следует `prefers-color-scheme`;
- `<html data-theme="light|dark">` задаёт тему принудительно;
- `data-theme` на отдельном блоке делает из него «островок» другой темы.

Переключатель из витрины хранит выбор в `localStorage` (ключ `lv-theme`). Каждое обращение к хранилищу обёрнуто в `try/catch`.

## Токены

| Группа | Переменные |
|---|---|
| Поверхности | `--paper`, `--stone`, `--raised`, `--night` |
| Текст | `--ink`, `--muted` |
| Акценты | `--bordeaux` (+`-strong`, `-soft`), `--blue` (+`-strong`, `-soft`), `--gold`, `--gold-text` |
| Линии | `--line` (декор), `--line-strong` (границы контролов, ≥3:1) |
| Декор | `--facade-field/-trim/-joint`, `--smalt-blue/-gold/-red/-green`, `--lamp` |
| Состояния | `--focus`, `--focus-halo`, `--focus-ring`, `--selection` |
| Семантика | `--bg`, `--bg-alt`, `--surface`, `--text`, `--text-muted`, `--accent`, `--accent-hover`, `--accent-2`, `--ornament`, `--rule` |
| Типографика | `--font-display`, `--font-text`, `--fs-xs … --fs-3xl` (clamp), `--fs-figure`, `--lh-*`, `--tr-*`, `--measure` |
| Ритм | `--sp-1 … --sp-11` (4/8), `--section-y`, `--container`, `--gutter`, `--grid-gap`, `--coffer` |
| Прочее | `--radius-*`, `--bw-*`, `--shadow-*`, `--dur-*`, `--ease-*`, `--z-*` |

Компоненты используют **семантические** алиасы. Поэтому раздел `.section--night` и класс `.surface-alt` переопределяют алиасы, а сами компоненты не меняются.

Брейкпоинты (указаны справочно в `tokens.css`): 460, 640, 760, 860 px.

## Цвета: правила

| Цвет | Роль | Можно | Нельзя |
|---|---|---|---|
| **Бордо** `--bordeaux` | Главный акцент | Ссылки, главная кнопка, цифры показателей, буквица, ключевая дата | Больше одной главной кнопки на экран; большие заливки фона |
| **Синий** `--blue` | Второй акцент, «служебный» | Планки сверху (навигация, подвал, таблица), даты хроники, «стало», вторичная кнопка, примечание | Конкурировать с бордо за главное действие |
| **Золото** `--gold` | Только декор и крупный текст | Ромбы, орнаментальные линейки, светильники кессонов, римские цифры от 24px **на бумаге** | Мелкий текст (3.09:1). Любой текст на `--stone` (2.75:1) |
| **Старое золото** `--gold-text` | Золото для мелкого текста | Кикер, метки карточек (5.52:1 на бумаге, 4.91:1 на камне) | — |
| Фасад, смальта | Иллюстрация | Полосы `.rustication`, `.smalt-band`, заглушки | Текст и элементы управления |

В тёмной теме золото светлое (8.5:1), и мелкий текст им допустим. Ограничение относится к светлой теме.

## Контраст (WCAG 2.2 AA)

Все используемые пары проходят в обеих темах:

- обычный текст — не меньше 4.5:1;
- крупный текст — не меньше 3:1;
- границы элементов управления и фокус — не меньше 3:1.

Полная таблица есть в витрине. Пересчитать её:

```sh
python3 design-system/contrast.py          # обновит таблицу в index.html
python3 design-system/contrast.py --check  # только проверка, код 1 при нарушении
```

## Доступность и движение

- Фокус: `:focus-visible` даёт кольцо 2px с отступом. У кнопок кольцо двойное (`--focus-ring`), его видно и на бордо.
- Декор (`.orn`, `.coffers`, римские цифры) помечается `aria-hidden="true"`.
- При `prefers-reduced-motion: reduce` все `--dur-*` равны 0, `.rv` показывается сразу, плавная прокрутка выключена.
- Минимальная высота кнопок 44px. Нет горизонтальной прокрутки на ширине 320–390px.
